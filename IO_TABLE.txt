PLC_HMI_PITSTART - AKTUALNA / PLANOWANA TABELA ADRESÓW
=========================================================

WEJŚCIA CYFROWE
---------------
X000    INVERTER_OK / AUTOMATE_PRESENT      -> M300
X001    PRACA / MANUAL_FREE (do ustalenia) -> M301
X002    STATUS_3                            -> M302
X003    STATUS_4                            -> M303
X027    RM5 CH1 / główne wejście impulsów  -> M320

OPCJONALNE WEJŚCIA RM5 PRZEZ AD
--------------------------------
AD0 -> D010   opcjonalny kanał RM5 (0-10V po interfejsie)
AD1 -> D000   opcjonalny kanał RM5 (0-10V po interfejsie)
AD2 -> D001   opcjonalny kanał RM5 (0-10V po interfejsie)
AD3 -> D002   opcjonalny kanał RM5; domyślnie wejście prądowe - wymaga konwersji/re-konfiguracji
AD4 -> D003   opcjonalny kanał RM5; domyślnie wejście prądowe - wymaga konwersji/re-konfiguracji
AD5 -> D004   opcjonalny kanał RM5; domyślnie wejście prądowe - wymaga konwersji/re-konfiguracji

UWAGA:
RM5 daje wyjścia NPN open-collector. Nie wolno traktować AD0...AD5 jak wejść cyfrowych
i łączyć ich bezpośrednio bez dopasowania elektrycznego.
Dla wejść 0-10V trzeba wytworzyć stan napięciowy 0/5-10V (np. pull-up/interfejs).
Dla wejść 0-20mA potrzebny jest interfejs prądowy albo kanał musi być skonfigurowany
jako napięciowy, jeśli dana wersja sprzętu na to pozwala.

WYJŚCIA - EMULACJA PITSTART
---------------------------
Y000    CREDIT / COMPTEUR
        impulsy kredytowe; 1 impuls odpowiada jednostce ustawionej przez projekt
        obecny generator: T201 K10 ON, T202 K10 OFF

Y001    PILOTAGGIO POMPA
        aktywne podczas pracy, jeśli opcja PILOTAGGIO_ENABLE jest włączona

Y002    PROGRAM 1
Y003    PROGRAM 2
Y004    PROGRAM 3
Y005    PROGRAM 4
Y006    PROGRAM 5
Y007    PROGRAM 6

Y023    RM5 INHIBIT
        /M300 -> Y23
        brak AUTOMATE_PRESENT/INVERTER_OK -> RM5 zablokowany

Y027    OŚWIETLENIE W CZASIE PRACY
        Y27 = WORK_ACTIVE

WAŻNE:
Y004 było używane w oryginalnej logice analogowej do MOV D6/D7.
Przed przeznaczeniem Y004 na PROGRAM 3 należy usunąć/przenieść stare zależności Y004 -> D6/D7.

REJESTRY D - RM5 / PITSTART
---------------------------
D300    mnożnik / parametr roboczy z HMI

D360    opcjonalny próg detekcji dla analogowego wejścia RM5

RM5 - STANDARDOWE ZŁĄCZE 10-PIN
--------------------------------
Pin 1    GND
Pin 2    +12...24 VDC
Pin 3    CH5
Pin 4    CH6
Pin 5    N.U. / zależne od konfiguracji
Pin 6    INHIBIT
Pin 7    CH1
Pin 8    CH2
Pin 9    CH3
Pin 10   CH4

PRZYKŁADOWE MAPOWANIE OPCJONALNE RM5 -> AD
-------------------------------------------
CH1 -> X027 (główne)
CH1..CH6 mogą alternatywnie zostać skierowane na AD0..AD5 po odpowiednim
dopasowaniu elektrycznym. Nie jest to połączenie bezpośrednie open-collector -> AD.
