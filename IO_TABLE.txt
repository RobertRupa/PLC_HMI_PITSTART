------------

M330    CREDIT ON phase
M331    CREDIT OFF phase

REJESTRY D
----------
D300    RM5 CH1 VALUE
        10 przy starcie; pole informacyjne / konfiguracyjne
        konwersja czasu używa D520

D320    impulsy bieżącej paczki RM5
        0 przy starcie

D330    kolejka CREDIT do Y000
        0 przy starcie - nie wolno wznawiać po restarcie

D350    pozostały czas [s]
        0 przy starcie
        odliczany tylko gdy M412=1
        max 32000

D351    rezerwa

D500    "V1"
D501    ".2"
D502    ".0"
D503    0
D504-D507 rezerwa stringu wersji

D516    VERSION_MAJOR = 1
D517    VERSION_MINOR = 2
D518    VERSION_PATCH = 0

D520    TIME_PER_RM5_PULSE_S
        HMI RW
        zakres 1...600
        domyślne 10 tylko jeśli wartość startowa jest niepoprawna

D521    LAST_PACKET_PULSES
D522    LAST_PACKET_TIME_S low word
D523    LAST_PACKET_TIME_S high word
D524    RM5_SESSION_PULSE_COUNTER, max 30000
D525    RM5_SESSION_EQUIV_TIME_S low word
D526    RM5_SESSION_EQUIV_TIME_S high word
D527    TIME_ADD_LIMIT_THRESHOLD = 32000 - D520

TIMERY
------
T200 K100    RM5 packet timeout ~1,0 s
T201 K10     CREDIT ON ~0,1 s
T202 K10     CREDIT OFF ~0,1 s

BITY SYSTEMOWE
--------------
M8000        zawsze ON
M8002        pierwszy skan
M8013        zegar 1 s, używany przez LDP

BEZPIECZNY START
----------------
D300 = 10
D320 = 0
D330 = 0
D350 = 0
D351 = 0
D521...D527 = 0 początkowo; D527 jest następnie obliczane z D520
D520 pozostaje bez zmian, jeśli 1...600; w przeciwnym razie = 10

M320 = 0
M321 = 0
M330 = 0
M331 = 0
M400...M406 = 0
M411 = 0
M412 = 0
M420...M425 = 0
M410 = 1

RM5 - STANDARDOWE ZŁĄCZE 10-PIN
--------------------------------
Pin 1    GND
Pin 2    +12...24 VDC
Pin 3    CH5
Pin 4    CH6
Pin 5    N.U. / zależne od konfiguracji
Pin 6    INHIBIT <- Y023
Pin 7    CH1 -> X027
Pin 8    CH2
Pin 9    CH3
Pin 10   CH4

PITSTART
--------
CN8 1-2    Presence automatic device -> X000
CN8 3-4    Manual / Free -> X013 -> M302

UWAGA
-----
W V1.2.0 Manual / Free jest tylko statusem. Nie omija D350 i nie uruchamia programu bez kredytu.
