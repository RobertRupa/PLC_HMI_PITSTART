PLC_HMI_PITSTART - AKTUALNA TABELA PROJEKTU
=================================================

WEJŚCIA PLC
-----------
X000    AUTOMATE_PRESENT / INVERTER_OK
        Główny sygnał zezwolenia.
        Brak sygnału blokuje RM5 przez Y023.

X001    PRACA
        Sygnał informacyjny z myjni.
        NIE jest blokerem RM5.

X004    PRZYCISK MECHANICZNY STOP
X005    PRZYCISK MECHANICZNY PROGRAM 1
X006    PRZYCISK MECHANICZNY PROGRAM 2
X007    PRZYCISK MECHANICZNY PROGRAM 3
X010    PRZYCISK MECHANICZNY PROGRAM 4
X011    PRZYCISK MECHANICZNY PROGRAM 5
X012    PRZYCISK MECHANICZNY PROGRAM 6
X013    MANUAL / FREE
X014    REZERWA
X027    RM5 CH1 - wejście impulsów

WYJŚCIA PLC
-----------
Y000    CREDIT / COMPTEUR
        T201 K10 ≈ 0,1 s ON
        T202 K10 ≈ 0,1 s OFF
        okres start-start ≈ 0,2 s

Y001    PILOTAGGIO POMPA
        M410 AND M412 -> Y001

Y002    PROGRAM 1
Y003    PROGRAM 2
Y004    PROGRAM 3
Y005    PROGRAM 4
Y006    PROGRAM 5
Y007    PROGRAM 6

Y023    RM5 INHIBIT
        /M300 -> Y023

Y027    OŚWIETLENIE
        M412 -> Y027

BITY M - STATUS / RM5
---------------------
M300    kopia/status X000
M301    kopia/status X001
M302    MANUAL_FREE status z X013
M320    impuls roboczy RM5 z X027
M321    aktywne zbieranie paczki RM5
M330    faza ON generatora CREDIT Y000
M331    faza OFF generatora CREDIT Y000

BITY M - HMI
------------
M400    HMI STOP
M401    HMI PROGRAM 1
M402    HMI PROGRAM 2
M403    HMI PROGRAM 3
M404    HMI PROGRAM 4
M405    HMI PROGRAM 5
M406    HMI PROGRAM 6
M410    PILOTAGGIO_ENABLE
M411    HMI RESET_RM5_SESSION_COUNTERS (przycisk chwilowy)
M413    TIME_PARAM_OK; 1 gdy D520 = 1...600

BITY M - POŁĄCZENIE PRZYCISKÓW HMI + FIZYCZNYCH
------------------------------------------------

M443    P3_CMD   = X007 OR M403

M446    P6_CMD   = X012 OR M406

BITY M - AKTYWNY PROGRAM
------------------------
M420    PROGRAM 1 ACTIVE
M421    PROGRAM 2 ACTIVE
M422    PROGRAM 3 ACTIVE
M423    PROGRAM 4 ACTIVE
M424    PROGRAM 5 ACTIVE
M425    PROGRAM 6 ACTIVE
M412    WORK_ACTIVE

REJESTRY D
----------
D300    RM5 CH1 VALUE / mnożnik
        wartość startowa = 10

D320    liczba impulsów aktualnej paczki RM5
        wartość startowa = 0

D330    kolejka impulsów CREDIT do wysłania na Y000
        wartość startowa = 0
        MUSI być zerowana przy starcie PLC

D350    pozostały czas w sekundach; dodawany z D520 i odliczany podczas WORK_ACTIVE
        wartość startowa = 0

D351    starsze słowo wyniku 32-bit MUL
        wartość startowa = 0

D500    PLC_VERSION_STRING word 0 = "V1"
D501    PLC_VERSION_STRING word 1 = ".2"
D502    PLC_VERSION_STRING word 2 = ".0"
D503    PLC_VERSION_STRING terminator = 0
D504-D507 zarezerwowane dla dłuższego stringu wersji

D516    VERSION_MAJOR = 1
D517    VERSION_MINOR = 2
D518    VERSION_PATCH = 0

D520    TIME_PER_RM5_PULSE_S
        parametr HMI RW; domyślnie 10 s/impuls
        prawidłowy zakres 1...600

D521    LAST_PACKET_PULSES
        liczba impulsów ostatniej zakończonej paczki

D522    LAST_PACKET_TIME_S - dolne słowo wyniku
D523    LAST_PACKET_TIME_S - górne słowo wyniku
        D522:D523 = D521 * D520

D524    RM5_SESSION_PULSE_COUNTER
        licznik impulsów od startu/resetu sesji

D525    RM5_SESSION_EQUIV_TIME_S - dolne słowo
D526    RM5_SESSION_EQUIV_TIME_S - górne słowo
        D525:D526 = D524 * D520

D527    TIME_ADD_LIMIT_THRESHOLD
        robocze: 32000 - D520

TIMERY
------
T200 K100    timeout końca paczki RM5 ≈ 1,0 s
T201 K10     Y000 CREDIT ON ≈ 0,1 s
T202 K10     Y000 CREDIT OFF ≈ 0,1 s

RM5 - STANDARDOWE ZŁĄCZE 10-PIN
--------------------------------
Pin 1    GND
Pin 2    +12...24 VDC
Pin 3    CH5
Pin 4    CH6
Pin 5    N.U. / zależne od konfiguracji
Pin 6    INHIBIT
Pin 7    CH1 -> X027
Pin 8    CH2
Pin 9    CH3
Pin 10   CH4

PITSTART - POTWIERDZONE SYGNAŁY WEJŚCIOWE
-----------------------------------------
CN8 1-2    Presence automatic device
CN8 3-4    Manual / Free -> X013 -> M302

UWAGA:
Lokalne przyciski wykorzystują X004...X012.
RM5 CH1 jest przypisany do X027 zgodnie z aktualną konfiguracją projektu.
