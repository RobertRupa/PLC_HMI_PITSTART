PLC_HMI_PITSTART - AKTUALNA TABELA PROJEKTU
=================================================

WEJŚCIA PLC
-----------
X000    AUTOMATE_PRESENT / INVERTER_OK
        Główny sygnał zezwolenia.
        Brak sygnału blokuje RM5 przez Y023.

X001    PRACA
        Sygnał informacyjny z myjni.
        NIE jest blokerem RM5.

X002    REZERWA / przyszły status
X003    REZERWA / przyszły status

X027    RM5 CH1 - wejście impulsów

WYJŚCIA PLC
-----------
Y000    CREDIT / COMPTEUR
        Generator impulsów:
        T201 K10 ≈ 0,1 s ON
        T202 K10 ≈ 0,1 s OFF
        okres start-start ≈ 0,2 s

Y001    PILOTAGGIO POMPA
        M410 AND M412 -> Y001

Y002    PROGRAM 1
Y003    PROGRAM 2
Y004    PROGRAM 3
Y005    PROGRAM 4
Y006    PROGRAM 5
Y007    PROGRAM 6 / opcjonalne

Y023    RM5 INHIBIT
        /M300 -> Y023

Y027    OŚWIETLENIE
        M412 -> Y027

BITY M - STATUS / RM5
---------------------
M300    kopia/status X000
M301    kopia/status X001

M320    impuls roboczy RM5 z X027
M321    aktywne zbieranie paczki RM5

M330    faza ON generatora CREDIT Y000
M331    faza OFF generatora CREDIT Y000

BITY M - HMI / STEROWANIE
-------------------------
M400    STOP
M401    PROGRAM 1 command
M402    PROGRAM 2 command
M403    PROGRAM 3 command
M404    PROGRAM 4 command
M405    PROGRAM 5 command
M406    PROGRAM 6 command / opcjonalne

M410    PILOTAGGIO_ENABLE
M412    WORK_ACTIVE

REJESTRY D
----------
D300    mnożnik / parametr z HMI

D320    liczba impulsów aktualnej paczki RM5
D330    kolejka impulsów CREDIT do wysłania na Y000

D350    wynik MUL D320 * D300 / wartość wyświetlana na HMI
D351    starsze słowo wyniku 32-bit MUL

TIMERY
------
T200 K100    timeout końca paczki RM5 ≈ 1,0 s
T201 K10     Y000 CREDIT ON ≈ 0,1 s
T202 K10     Y000 CREDIT OFF ≈ 0,1 s

BIT SYSTEMOWY
-------------
M8013        zegar 1 s; używany zboczowo do DEC D350

RM5 - STANDARDOWE ZŁĄCZE 10-PIN
--------------------------------
Pin 1    GND
Pin 2    +12...24 VDC
Pin 3    CH5
Pin 4    CH6
Pin 5    N.U. / zależne od konfiguracji
Pin 6    INHIBIT
Pin 7    CH1 -> X027
Pin 8    CH2
Pin 9    CH3
Pin 10   CH4

PITSTART - POTWIERDZONE SYGNAŁY WEJŚCIOWE
-----------------------------------------
CN8 1-2    Presence automatic device
           HIGH/obecność sygnału = automat obecny.
           Brak sygnału może przełączyć PitStart w OUT OF SERVICE.

CN8 3-4    Manual / Free
           Obecność napięcia = ciągła praca bez monet.

UWAGA:
PRACA (X001) jest sygnałem specyficznym dla naszej myjni; instrukcja PitStart
nie definiuje osobnego standardowego wejścia RUN/PRACA.
