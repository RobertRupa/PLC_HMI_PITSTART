## Dane egzemplarzowe

Parametry HFU / Dim. / LF / HFL / Amp. oraz wartości Standby/Reference są zależne od konkretnego akceptora RM5.

Nie należy kopiować tych wartości do innego urządzenia.

## Interfejs programujący

Clone5 Professional komunikuje się z RM5 po interfejsie szeregowym TTL. W używanej konfiguracji adapter USB-UART musi być przypisany w Windows jako `COM1`.

Szczegóły połączenia i pinout są opisane w `docs/RM5.md`.
