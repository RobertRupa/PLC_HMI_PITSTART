# Zrzuty Clone5 Professional — RM5 Evolution

Docelowe pliki używane przez `docs/RM5.md`:

- `clone5_control.png` — Control / diagnostyka,
- `clone5_channels_1_10.png` — kanały 1–10,

- `clone5_calibration.png` — Calibration,
- `clone5_com1.png` — połączenie / konfiguracja portu COM1.

## Uwaga o kalibracji

Zrzut `clone5_calibration.png` dokumentuje dane konkretnego egzemplarza RM5. Wartości kalibracyjne nie są ustawieniami uniwersalnymi i nie powinny być przepisywane do innego akceptora.

## Interfejs programujący

RM5 jest programowany przez interfejs szeregowy TTL. W użytej konfiguracji Clone5 Professional urządzenie jest wykrywane po przypisaniu adapterowi numeru `COM1`.

Szczegóły połączenia są opisane w `docs/RM5.md`.
