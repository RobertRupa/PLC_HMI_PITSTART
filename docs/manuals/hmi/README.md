## WSB HMI&PLC All-in-one User Manual V1.79

Plik:

```text
WSB_HMI_PLC_All_in_one_User_Manual_V1.79.pdf
```

To podstawowa instrukcja dla sprzętu używanego w projekcie. Manual obejmuje serię WSB, w tym model **WSB7020R**.

Zawiera m.in.:
- parametry sprzętowe i zasilanie,
- wymiary i montaż,
- porty HMI/PLC,
- programowanie HMI,
- komunikację HMI <-> PLC,
- opis RS232/RS485,
- I/O i analog,
- schematy połączeń,
- podstawowe informacje o programowaniu PLC.

Producent wskazuje HMI Studio 5.1 do programowania części HMI oraz GX Developer / GX Works2 do części PLC.

Po ręcznym uploadzie:
[Otwórz lokalny manual WSB V1.79](WSB_HMI_PLC_All_in_one_User_Manual_V1.79.pdf)

## WSC HMI&PLC All-in-one User Manual V1.13

Plik:

```text
WSC_HMI_PLC_All_in_one_User_Manual_V1.13.pdf
```

To dokumentacja nowszej/innej rodziny WSC/WSCH. **Nie jest podstawowym manualem dla WSB7020R**, ale jest przydatna jako materiał porównawczy dla HMI/PLC Winsun/SEEKU.

Obejmuje m.in.:
- WSC7020R/WSC7020T/WSC7020RT,
- HMI Studio 5.1,
- RS232/RS485 i opcjonalny CAN/Ethernet,
- komunikację z Mitsubishi FX3U,
- programowanie i diagnostykę.

Ustawień z manuala WSC nie należy automatycznie przenosić do WSB7020R bez potwierdzenia dla konkretnego panelu.

Po ręcznym uploadzie:
[Otwórz lokalny manual WSC V1.13](WSC_HMI_PLC_All_in_one_User_Manual_V1.13.pdf)
